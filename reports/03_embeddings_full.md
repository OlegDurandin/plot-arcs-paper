# Тематический канал на эмбеддингах полного корпуса

Решение Ворот 5/6, п. 5 (2026-11-26). multilingual-e5-small, сегменты N = 20 целиком (без усечения: куски по предложениям, длинные предложения — окнами по токенам), косинусное расстояние. Тексты within_author_cap (169595 из 244756 с метриками). Размер сегмента — содержательных лемм, медиана по тексту.

Метрики: **сырая скорость** (среднее расстояние соседних сегментов); **внутритекстовое попарное** (средний разброс сегментов текста); **нормированная скорость** = скорость / попарное — основная (Ворота 3); ожидание при случайном порядке сегментов = 1, поэтому значение < 1 — **последовательная связность**. Связность текста проверяется перестановкой сегментов (100 перестановок, p ≤ 0.05).
