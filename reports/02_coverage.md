# Этап 2. Покрытие лексиконами

Сегменты N = 20, документы из анализа (`include`, единицы text и linked_work). «доля_слов» — доля токенов сегмента, найденных в лексиконе (по сумме слов группы); «сегм_≥1» — доля сегментов хотя бы с одним найденным словом.

Лексиконы (после приведения к леммам pymorphy3): {"rusentilex": {"entries_single": 11047, "phrases_skipped": 2751, "pos": 2409, "neg": 7301}, "linis_crowd": {"entries": 7601, "polar": 2797}, "nrc_emolex_ru": {"entries_with_category": 5420, "multiword_skipped": 299}}

RSL_любые — все однословные записи RuSentiLex (вкл. нейтральные и контекстно-зависимые); RSL_полярные — только positive/negative; Linis_|≥0,5| — слова LinisCrowd со средней оценкой не меньше 0,5 по модулю; NRC — слово хотя бы с одной из 10 категорий.
