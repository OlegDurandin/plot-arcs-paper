# Эмоциональные и тематические дуги русской прозы разных форм

Исследование для конференции «Диалог». Сравниваются волшебная сказка (Афанасьев), переводная сказка (fairytalez),
рассказ, новелла, повесть, роман (Проза.ру) и фанфик-ориджинал (Ficbook) — по дугам тональности и тематическим
траекториям, с нулевыми моделями и контролем длины.

- `PLAN.md` — план по этапам и решения ворот;
- `experiment_results.md` — журнал: что сделано, параметры, результаты, неожиданное, решения;
- `REPRODUCE.md` — как воспроизвести результаты;
- `src/` — код этапов (`sNN_*.py`), `configs/` — параметры, `reports/` — отчёты и рисунки.

Корпуса и промежуточные расчёты в репозиторий не входят (см. `REPRODUCE.md`, раздел 2).
